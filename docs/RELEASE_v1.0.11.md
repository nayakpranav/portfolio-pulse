# FolioLens Personal v1.0.11

PR #3 is merged with its reviewed head `18602114756e7e6285abf384e041115db241ab93`
retained in normal Git history. The stable version removes the development suffix.

## Changes

- Optional graphical EUR-per-unit derivative observations, source/date checks,
  seven-day freshness and exact-activity-bound encrypted local persistence.
- Saved personal quotations cannot be inherited by hosted/public defaults.
- Current-price freshness and future-FX-date guards; truthful provider/date
  diagnostics; no requests for unverifiable derivative identities.
- Expandable historical-price and forward-dividend evidence in the personal
  dashboard and offline HTML, retaining the eight headline metrics.
- Optional, isolated QuantStats validation. Application dependencies, canonical
  accounting and the PDF's one-page landscape design remain unchanged.
- Frozen TLS/chart startup checks and conditional packaging of the build
  interpreter's required public SSL trust-policy resource. Verification is not
  disabled and operating-system trust stores are not modified.
- Repeated recognition of an unchanged verified event no longer rewrites its
  encrypted record. Existing evidence is retained byte-for-byte unless new
  validated evidence is actually added or valid backup recovery is required.

## Release gates

The source, full regression/security suite, optional independent validation,
Windows frozen worker/TLS/chart/report checks and public-source privacy scan must
pass. Private acceptance uses the authorized export and original V6.7.8 reference
with identical captured prices, FX, dates and event evidence. Real artifacts,
captures and profile records stay outside Git and release packages.

The generic Windows ZIP includes SHA-256 checksums and a complete file manifest.
Install side by side before changing the existing shortcut. Preserve a verified
backup of the prior executable, shortcut configuration, private settings and
reports. Promotion follows successful local acceptance; rollback restores the
previous shortcut without replacing the user's profile. No Python installation
is required. Standard Windows warnings for an unsigned executable may appear.

## Continuing limitations

Unpriced derivatives retain incomplete full-portfolio value/profit. Manual quotes
remain optional and are never replaced with zero, cost or old executions.
Historical estimates and incomplete forward net-distribution evidence remain
qualified. Public CSV uploads and live market requests remain disabled on the
synthetic website. No new provider rights, brokerage access, trades, scrapers or
paid services are introduced. Holy Grail remains unchanged.
