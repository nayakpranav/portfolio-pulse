# FolioLens Personal v1.0.14

Production promotion of the owner-tested Portfolio Intelligence release from PR #7.
The seven optional read-only enhancements are documented in
[Portfolio Intelligence](PORTFOLIO_INTELLIGENCE.md). The eight headline metrics,
canonical financial definitions, manual evidence and fast batch replay are retained.

Final presentation refinements add an accessible responsive drawdown legend,
solid cyan portfolio and dashed golden-yellow benchmark lines, and a softer cyan
underwater fill. Wealth uses the same golden benchmark accent on screen and in
offline HTML. Axes, dates, observations and calculations are unchanged. The profit
attribution position-group table now explicitly includes non-security cash interest
from its existing canonical component, without counting it twice.

The approved development baseline passed 401 regressions, nine canonical synthetic
comparisons, all 126 protected definitions and 36 controlled private result fields.
Focused polish tests and Linux/Windows CI validate the release changes. Generic
Windows packaging, checksums, TLS/worker/report startup, private profile protection,
actual shortcut launch and clean shutdown are production acceptance gates.

The existing one-page landscape PDF design remains unchanged. Offline HTML keeps
its CSP, escaping, keyboard controls and session-specific downloads. Public CSV
uploads remain disabled. No providers, dependencies or quotation collectors are
added. Experimental PR #4 and Holy Grail are not modified.

Extract the entire Windows ZIP and open **Open FolioLens Personal.exe**. No Python
installation is needed. The executable is unsigned; standard Windows warnings may
appear. Personal evidence remains outside the generic package. The previous v1.0.13
application, shortcut configuration and private-profile backup are retained locally
for rollback; installation never resets saved financial evidence.
